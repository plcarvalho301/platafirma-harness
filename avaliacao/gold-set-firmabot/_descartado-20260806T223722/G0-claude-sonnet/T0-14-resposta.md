**Vocabulário controlado**, segundo a fonte, é o resultado do processo de *vocabulary control* — a disciplina de organizar termos para descrever conteúdo com consistência. O padrão não entrega, nos trechos que chegaram, uma definição isolada do substantivo "controlled vocabulary" (essa entrada estaria no Glossário do Apêndice, que não veio); o que chegou é a definição do processo e dos princípios que o constituem.

**Propósito** (transcrito de [3], Introduction):
> "Vocabulary control is used to improve the effectiveness of information storage and retrieval systems, Web navigation systems, and other environments that seek to both identify and locate desired content via some sort of description using language. The primary purpose of vocabulary control is to achieve consistency in the description of content objects and to facilitate retrieval."

**Como se alcança** (transcrito de [2], 1.2):
Vocabulary control é atingido por três métodos principais:
- definir o escopo/significado dos termos;
- usar a relação de equivalência para ligar sinônimos e quase-sinônimos;
- distinguir entre homógrafos.

**Princípios que orientam o desenho** (transcrito de [6], 5.3):
Quatro princípios guiam a construção de um vocabulário controlado:
- eliminar ambiguidade;
- controlar sinônimos;
- estabelecer relações entre termos onde apropriado;
- testar e validar termos.

Complemento derivado de [6]: o objetivo central é que cada conceito distinto seja descrito por uma única forma linguística — se existem múltiplas formas, elas devem ser controladas/regularizadas para que o conteúdo não se espalhe por múltiplos pontos de acesso no sistema.

**Unidade básica: o termo** (transcrito de [8], 5.2.1):
> "a term is defined to be one or more words used to represent a concept." Termos são selecionados da linguagem natural para compor o vocabulário controlado, e o padrão usa "term" genericamente tanto para "preferred terms" quanto para "entry terms" (não-preferidos).

**Escopo de aplicação** (transcrito de [5], Abstract): o padrão foca em vocabulários controlados monolíngues usados na representação de content objects em knowledge organization systems, incluindo listas, synonym rings, taxonomias e tesauros.

Observação sobre a leitura das fontes: a fonte [4] traz a seção de Definições (4.1) do padrão, mas o trecho recuperado lista outros termos (associative relationship, authority file, broader term, browsing, candidate term, category) e é cortado antes de chegar à entrada "controlled vocabulary" propriamente — por isso não posso transcrever essa definição lexical específica; o que ofereço acima é a caracterização operacional do conceito nas seções 1 e 5.
