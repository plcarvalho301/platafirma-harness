O grafo de conceitos vive em acervo.conceito + conceito_relacao; conceito_aresta é view (união coluna mais_amplo_id + tabela conceito_relacao, ambos os sentidos para relacionada/disjunta). OWL/RDF é projeção read-only da relacional (ont:0086: owl:disjointWith ← relacao.disjunta, owl:AllDisjointClasses ← filhos_exclusivos) — nunca editar OWL, nunca tratar como fonte. Cargo (wiki) é vitrine de outra ontologia (referências/frentes, BFO/CCO), sistema separado do grafo de conceito do acervo — não confundir os dois grafos. Views conf_conceito_generica_categoria/conf_conceito_relacao_categoria conferem se a natureza (mapeada a BFO: modelo=ICE, disposicao=disposition, processo/fenomeno=process) bate entre pai e filho em aresta generica/partitiva/instancia — pai e filho de categoria BFO diferente numa hierárquica é sinal de fundamento de divisão furado.
